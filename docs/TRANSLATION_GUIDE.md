# 도카폰! 분노의 철검 (PS1) 번역 지침

게임: ドカポン！怒りの鉄剣 (1996, 아스믹). 4인 보드게임 + RPG. 말투는 가볍고 장난스러운 코미디 톤.
기계 번역 금지. 직접 자연스러운 한국어로 옮긴다.

## 입력 형식 (text/in/*.tsv)
`id<TAB>cap<TAB>w<TAB>일본어` — 한 줄에 문자열 하나.
- `⏎` = 줄바꿈
- `{xxxx}` = 제어 코드. **순서와 개수를 그대로 유지**한다. (예외: `{9300}`/`{9400}` 은 반각 모드 켜기/끄기이므로 가타카나만 감싼 경우 지워도 된다. 숫자·영문을 감싼 경우는 남긴다.)
  - `{81ff}` 이름(문자열) 삽입, `{80ff}`/`{80xx}` 숫자 삽입, `{83xx}` 글자색 변경(`{8300}` 원래 색), `{84xx}` 가로 위치, `{85xx}` 세로 위치, `{9100}` 버튼 대기, `{9200}` 창 지우기(새 페이지)
  - 조사: `{81ff}` 뒤 조사는 받침을 알 수 없으므로 `은(는)` 대신 자연스럽게 피하거나 `{81ff}{8300}의`, `{81ff}{8300}에게` 처럼 받침과 무관한 조사를 쓰거나, 어쩔 수 없으면 `이(가)`, `을(를)`, `은(는)`, `와(과)`, `(으)로` 식으로 쓴다(길이가 허락할 때).

## 출력 형식 (text/ko/같은이름.tsv)
`id<TAB>한국어` — 입력의 모든 id를 같은 순서로. 빠뜨리지 말 것.

## 길이 제한 (자동 검사됨)
- **단위 수 ≤ cap-1**: 한글 1자, 공백 1, 기호 1, 숫자/영문 1, `⏎` 1, 제어코드 1개 = 각각 1단위.
- **줄 폭 ≤ w** (반각 칸 단위): 한글·전각기호 = 2칸, 공백 = 1칸, 숫자/영문 = 2칸(단 `{9300}`~`{9400}` 안에서는 1칸), `{80xx}` = 4칸, `{81ff}` = 12칸으로 계산.
- 한 페이지(`{9200}` 사이)의 줄 수는 원문보다 늘리지 않는다. 줄바꿈 위치는 자유롭게 옮겨도 된다.
- 메뉴처럼 `{84xx}`(위치)나 전각 공백으로 칸을 맞춘 문자열은 각 항목이 원래 칸 폭 안에 들어가게 맞춘다. 공백 문자 `　`(전각, 2칸)도 사용 가능.
- 검사: `python tools/ko.py text/ko/파일.tsv` → `오류 0` 이 될 때까지 고친다.

## 허용 문자
한글(가~힣), 공백, 숫자, 영문, 그리고 `! ? ~ & : % + - / ( ) , . … ' " ♥ ・ 「 」 ×`. 일본어 가나/한자는 금지.
`、` `。` 대신 `,` `.` 를 쓴다. `．．．` 같은 말줄임은 `…` 나 `...` 로.

## 용어
- text/glossary.tsv 의 고유명사(아이템·마법·몬스터·지명·인물)를 반드시 따른다.
- 화폐 G 그대로. HP 그대로. 레벨, 경험치, 공격력, 방어력, 마력, 속도(す早さ), 체력.
- ドカポン = 도카폰. 神様 = 신님. 魔王 = 마왕. 村 = 마을, 町 = 도시(町)… 문맥에 맞게.
